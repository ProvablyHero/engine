# Security reports

For vulnerabilities that could expose private data or bypass input/resource limits, email **hey@proveitbro.com** with the affected version and a minimal reproducer. Keep sensitive details out of public Issues.

Public numerical errors and mismatches using already revealed seeds can be reported in [Issues](https://github.com/ProveItBro/engine/issues). Please include the engine and adapter versions.

This engine does not need API keys, database credentials, a casino login or server infrastructure. Historical revealed seeds under `test-vectors/` are intentional replay fixtures. Never submit account credentials, cookies, private keys or unrevealed seeds.
