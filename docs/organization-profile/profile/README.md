# ProveItBro

**Casino says it's fair? Check the calculation.**

[ProveItBro](https://proveitbro.com) provides browser-based tools to explore Plinko probabilities, simulate sessions and replay supported revealed bets. Calculations are reproducible; the house edge still applies.

- **[Website & tools](https://proveitbro.com/plinko)** — demo, odds, calculator and session simulator.
- **[Engine](https://github.com/ProveItBro/engine)** — MIT TypeScript code, tests, CI and versioned replay adapters. BCH.games Plinko is verified against captured disclosed rounds; Stake Plinko is reference only.
- **Data (phase 1)** — versioned multiplier JSON, algorithm notes, source captures and CSV downloads. Intended license: CC BY 4.0. A public repository link will be added after its separate review.
- **[Methodology](https://proveitbro.com/methodology)** — what the numbers and verification statuses establish.

Found a calculation mismatch? [Report it in engine Issues](https://github.com/ProveItBro/engine/issues) with the version and a reproducible example using already revealed seeds.

No operator endorsement. No prediction of future bets. Affiliate relationships are disclosed on the website.
